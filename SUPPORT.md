# Getting Support

Thank you for using Crypto Service Suite. Here is the recommended way to seek assistance.

## Documentation First

Most questions are covered in the project documentation:

- [README.md](README.md) — overview, architecture, capabilities, and quick start.
- [DEVELOPMENT.md](DEVELOPMENT.md) — local setup, build commands, and CI gates.
- [ARCHITECTURE.md](ARCHITECTURE.md) — detailed system design and module relationships.
- [MIGRATION.md](MIGRATION.md) — upgrade paths and migration instructions.
- [API Reference (TypeDoc)](https://sebastienrousseau.github.io/crypto-service/) — complete TypeScript API documentation.

## Community Discussions

For general questions, architecture discussions, or usage help:

- Open a discussion in [GitHub Discussions](https://github.com/sebastienrousseau/crypto-service/discussions).

## Bug Reports

If you discover a bug:

- Check existing issues to see if it has already been reported.
- Open a [new issue](https://github.com/sebastienrousseau/crypto-service/issues/new?template=bug-report.md) with a minimal reproducible code sample, your Node.js and pnpm versions, and expected vs. actual behavior.

## Security Vulnerabilities

**Do not open public GitHub issues for security vulnerabilities.**
Please report security issues privately according to the process outlined in [SECURITY.md](SECURITY.md).
