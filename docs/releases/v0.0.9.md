# Crypto Service 0.0.9

## Highlights ⭐️

- **PASETO v4.local that other libraries can read**: `v4local` now follows the PASETO v4 specification and reproduces the official test vectors byte for byte. Tokens issued by 0.0.8 and earlier no longer decrypt and must be re-issued; v4.public tokens are unaffected.
- **npm provenance**: the release now attaches a provenance attestation to every npm package and fails if any is missing. 0.0.8 was published without one.
- **Current toolchain**: ESLint 10 with a single flat config, chai 6 and mocha 12 across all 18 packages, with the functions the stricter complexity rule exposed refactored rather than exempted. TypeScript stays on 5.9 until typescript-eslint, TypeDoc and ts-node support TypeScript 7.
