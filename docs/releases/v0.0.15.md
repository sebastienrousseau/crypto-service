# Crypto Service 0.0.15

## Highlights ⭐️

- **Native Google Cloud KMS Provider**: `@sebastienrousseau/crypto-kms` adds a production native `GcpKmsProvider` backed by Google Cloud KMS REST v1 API with zero external SDK dependencies, supporting key management, crypto operations, and key wrapping.
- **Post-quantum hybrid HPKE REST & SDK**: `@sebastienrousseau/crypto-server` exposes `/v2/hpke/keygen`, `/v2/hpke/seal`, and `/v2/hpke/open`; `@sebastienrousseau/crypto-sdk` adds typed client methods with server key custody.
- **HPKE CLI & interactive demo animation**: `@sebastienrousseau/crypto-cli` introduces `hpke` subcommands; root README gains an interactive terminal animation recorded from `.github/demo.tape` via VHS.
