# Crypto Service 0.0.6

## Highlights ⭐️

- **Authentication fails closed**: crypto-server refuses requests unless `CRYPTO_API_KEY` or `JWT_SECRET` is set (or `ALLOW_ANONYMOUS=1`), refuses to start in production without a credential, and enforces JWT on every route.
- **Key custody**: `/v1/revoke` no longer returns the server's private key, generated keys are never written into the keystore directory, and production refuses the bundled test keys.
- **Crypto fixes**: streaming AEAD rejects truncated streams, Shamir splitting rejects secrets it would have altered, KDF and Argon2 costs are bounded, crypto-edge no longer installs a `Math.random` fallback, and the MCP tools use real keys.
- **Accurate claims**: FIPS 140-3, HSM, multi-cloud KMS, WebAssembly, DORA/CRA compliance and unmeasured benchmark claims are removed from the README, docs and website.

> 0.0.6 is superseded by 0.0.7, which fixes further security issues (including a PAKE login that could be forged without the password) and makes crypto-server and crypto-cli installable from npm. Use 0.0.7.
