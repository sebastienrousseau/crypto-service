# Crypto Service 0.0.11

## Highlights ⭐️

- **Multi-recipient post-quantum streaming AEAD**: Authenticated encryption combining X25519, ML-KEM-768, and XChaCha20-Poly1305 with per-recipient slot CEK wrapping across `crypto-lib`, `crypto-server`, and `crypto-sdk`.
- **Multi-recipient CLI & MCP tooling**: `crypto-cli stream multi-encrypt` and `multi-decrypt` alongside MCP tools enable multi-recipient streaming operations with automated buffer zeroing.
- **Security hardening & CodeQL remediation**: Route-level rate limiting on sensitive server endpoints, secure Map dispatch eliminating prototype pollution risks, and clean lockfile audit.
