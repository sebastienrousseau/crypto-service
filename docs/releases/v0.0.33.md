# crypto-service 0.0.33

## Highlights ⭐️

- **pnpm 11 and security overrides that apply**: the 22 dependency overrides were silently ignored under pnpm 9. On pnpm 11.9.0 they apply, so `katex` resolves 0.19.0 and `markdown-it` 14.3.3, clearing every open Dependabot alert. The Docker image builds with `pnpm deploy --legacy`.
- **Stricter complexity gate**: `make check` and CI now also enforce cognitive complexity ≤ 15 and Halstead difficulty ≤ 30 per function, next to cyclomatic ≤ 10 and 60 lines. Existing offenders are recorded in a baseline that may only shrink.
- **No startup deprecation warning**: crypto-server no longer sets `disableRequestLogging`, so Fastify's FSTDEP023 warning is gone; request logging stays on.
- **Docs that match the code**: the README documents the CLI's real subcommands and the server's full configuration, and the terminal demo is re-recorded against 0.0.33.
