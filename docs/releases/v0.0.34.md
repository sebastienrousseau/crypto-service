# crypto-service 0.0.34

## Highlights ⭐️

- **Accurate, searchable npm pages**: all 18 package descriptions lead with what the package does and the terms people search for (post-quantum, ML-KEM, ML-DSA, SLH-DSA, HPKE), and every package has keywords. Eight had none.
- **No overstated claims**: `crypto-wasm` is described as the placeholder it is (no WebAssembly module ships yet), `crypto-kms` as AWS and local providers with three stubs, and `crypto-middleware` as Express and Fastify. `crypto-cbom` no longer claims DORA or CRA compliance. Each claim was checked against the package source.
- **Package READMEs fixed too**: the `crypto-wasm` README documents the real loader and fallback, and the ecosystem table in 14 package READMEs lists all 18 packages with links that work on npm.
- **Release checks catch stale metadata**: the release now fails unless `CITATION.cff` `date-released` matches the version's CHANGELOG date, and every Markdown file and `scripts/` are checked by Prettier in CI.
