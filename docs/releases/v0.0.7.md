# Crypto Service 0.0.7

## Highlights ⭐️

- **Installable and runnable**: crypto-server and crypto-cli declare their runtime dependencies, a pack-and-install smoke test guards it in CI, and the Docker image starts, runs as non-root and health-checks `/ready`.
- **Protocol correctness**: the PAKE is now RFC 9807 OPAQUE, HPKE matches the RFC 9180 test vectors, ISO 20022 signatures verify against trusted keys, and hybrid KEMs bind ciphertexts and public keys. Outputs from 0.0.6 for these do not interoperate.
- **Data at rest**: Prisma and TypeORM field encryption fails closed and binds ciphertexts to their field; KMS key rotation keeps earlier versions; rate-limited requests get 429 instead of 500.
- **Real gates**: lint covers tests, format, complexity and markdownlint checks block CI, actions are pinned by SHA, and the suite runs on Windows.
