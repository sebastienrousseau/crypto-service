# Crypto Service 0.0.12

## Highlights ⭐️

- **Post-quantum hybrid HPKE (RFC 9180 + ML-KEM-768)**: `crypto-lib` implements quantum-safe HPKE combining DHKEM(X25519) with ML-KEM-768 encapsulation under RFC 9180 labeled key combiners.
- **HashiCorp Vault KMS & key wrapping**: `crypto-kms` adds a native `VaultKmsProvider` backed by Vault Transit engine, plus unified `wrapKey` and `unwrapKey` across all providers.
- **OPAQUE zero-knowledge authentication (RFC 9807)**: `crypto-server` and `crypto-cli` implement RFC 9807 OPAQUE-3DH REST routes and CLI commands with enumeration resistance and single-use login handshakes.
