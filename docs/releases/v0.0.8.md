# Crypto Service 0.0.8

## Highlights ⭐️

- **On npm, with provenance**: all 18 packages are published to npm from CI with build provenance for the first time. Install with `pnpm add @sebastienrousseau/crypto-lib` (and the other packages) instead of building from source.
- **Release safety**: every manifest declares the repository npm provenance checks against, and the release workflow refuses to publish when a manifest or the tag is wrong, or when the npm token is missing.
- **Same code as 0.0.7**: no library or server behaviour changes; see the 0.0.7 release for the security fixes and the RFC 9807 OPAQUE PAKE.
