# Crypto Service 0.0.10

## Highlights ⭐️

- **Post-quantum streaming framework integrations**: `@sebastienrousseau/crypto-edge`, `@sebastienrousseau/crypto-react`, `@sebastienrousseau/crypto-vue`, and `@sebastienrousseau/crypto-middleware` provide native post-quantum hybrid streaming adapters with WHATWG streams and automatic memory scrubbing.
- **Server key storage envelope encryption**: `crypto-server` encrypts server-persisted private keys on disk with AES-256-GCM and tenant-bound authenticated additional data.
- **SDK resilience & W3C tracing**: `crypto-sdk` adds automated retries and timeout controls; `crypto-server` and `crypto-sdk` propagate W3C Trace Context traceparents.
- **CBOM quantum security classifications**: `crypto-cbom` detects post-quantum and hybrid algorithms with RFC and NIST FIPS classifications.
