# Benchmarks

## Status

This page publishes no benchmark numbers. The table previously shown here
(AES-256-GCM 1,420 MB/s, BLAKE3 2,100 MB/s, Argon2id 42 ms and others) was
not produced by any committed benchmark code and has been removed.

Numbers will be added back only when they are generated by the committed
benchmark script below, with the Node.js version, operating system, CPU and
iteration count recorded next to them.

## Running the benchmarks

The benchmark script is [`benchmarks/crypto-bench.ts`](../benchmarks/crypto-bench.ts).
It times the compiled output of crypto-lib and several sibling packages,
so build the workspace first:

```bash
pnpm install
pnpm -r run build
node benchmarks/crypto-bench.ts --iterations 500
```

The script runs directly on Node.js versions that strip TypeScript types by
default (checked on Node.js 24.21.0). It prints operations per second, mean latency and,
where relevant, throughput for each operation, followed by the Node.js
version and platform. Use `--filter <pattern>` to run a subset.

The [`benchmark.yml`](../.github/workflows/benchmark.yml) workflow runs the
same script in CI.

The `@sebastienrousseau/crypto-benchmarks` package offers a separate harness
(`crypto-benchmarks --suite <all|symmetric|asymmetric|pqc|hash>`) that
compares classical and post-quantum primitives.

## Interpreting results

Results depend on hardware, operating system, Node.js version and system
load. Run on an otherwise idle machine, repeat several times, and treat
differences within run-to-run variation as noise. Numbers are not service
level guarantees.
