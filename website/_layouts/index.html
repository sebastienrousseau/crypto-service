Quick start

ML-KEM-768 in three calls.

Install @sebastienrousseau/crypto-lib on Node.js 22 or later, then generate a key pair, encapsulate a shared secret and recover it. Keys, ciphertexts and secrets are hex strings.

crypto-lib API reference

Project facts

  • 18 npm packages, one version
  • 6 language SDKs over the REST API
  • 100% statement, branch, function and line coverage in every package
  • FIPS 203/204/205 algorithms, not a validated module
